### Product Overview

The TwinMOS USB Hub 4-Port S-Shape is a compact bus-powered USB 3.0 hub designed to multiply a single host USB port into four independent downstream USB Type-A ports. Its distinctive ergonomic S-shaped housing differentiates it from conventional rectangular hubs, reduces cable tangling at the desk edge, and provides a non-slip base for stable placement. The hub is equally suited for desktop workstations, laptop users, and conference-room setups where USB port scarcity is a common bottleneck.

Supporting USB 3.0 / USB 3.2 Gen 1 data rates of up to 5 Gbps across all ports (bandwidth shared), the S-Shape hub accommodates simultaneous connection of peripherals including keyboards, mice, flash drives, external HDDs, and charging devices. Full backward compatibility with USB 2.0 and USB 1.1 devices ensures that legacy peripherals operate without issue alongside modern high-speed devices. The plug-and-play design requires no driver installation under Windows, macOS, Linux, and Chrome OS.

### Key Features

1. **S-Shape Ergonomic Design** — Unique S-profile housing fits naturally at the edge of a desk or laptop stand, keeping cables organised and reducing port-access obstruction; non-slip ABS base prevents accidental movement.
2. **4 × USB 3.0 Downstream Ports** — Quadruples a single host USB port; simultaneously supports keyboards, mice, flash drives, card readers, and other USB Mass Storage or HID devices.
3. **USB 3.2 Gen 1 SuperSpeed (5 Gbps)** — Shared 5 Gbps upstream bandwidth supports fast data transfers to external storage devices, significantly outperforming USB 2.0 hubs for file-transfer tasks.
4. **Bus-Powered — No External Adapter** — Draws power from the host USB port; clutter-free setup with a single cable and no desk-bound power brick required.
5. **Full USB Backward Compatibility** — USB 2.0 and USB 1.1 devices (keyboards, mice, legacy peripherals) connect and operate without adapters or speed penalties.
6. **Power / Activity LED Indicator** — Visual indicator confirms hub power-on status and flashes during active data transfer, simplifying troubleshooting in multi-device setups.
7. **Universal Plug-and-Play** — Compliant with USB Hub Class specification; no driver installation required on Windows 10/11, macOS 10.12+, Linux 3.0+, and Chrome OS.

### Disclaimer

All specifications are subject to change without notice. The 5 Gbps data rate is the aggregate upstream bandwidth shared across all four downstream ports; actual per-device throughput decreases when multiple high-speed devices transfer data simultaneously. Per-port power delivery of 500 mA is subject to the host port's total current budget; TwinMOS Technologies recommends connecting power-hungry devices (external HDDs, bus-powered fans) to USB ports directly on the host when the hub is loaded with multiple devices. TwinMOS Technologies is not responsible for peripheral damage caused by overcurrent conditions originating from non-compliant third-party devices. This hub is not designed for use with USB-PD charging standards above 5 V; do not attempt to charge USB-PD devices requiring 9 V/12 V/20 V profiles via this hub.
