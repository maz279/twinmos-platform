## RGB vs ARGB: An Important Distinction

Not all RGB memory is the same. Understanding the difference before purchasing is essential:

| Feature | Standard RGB (12V) | Addressable RGB / ARGB (5V) |
|---------|-------------------|------------------------------|
| Header type | 4-pin, 12V | 3-pin, 5V |
| LED control | Entire module one color at a time | Each LED individually controlled |
| Effects possible | Static, breathing, color cycles | Wave, rainbow, chase, per-zone — unlimited patterns |
| Ecosystem sync | Works with 12V RGB headers | Works with 5V ARGB headers |

**Concord RGB modules use 5V ARGB technology** — per-LED addressable lighting that enables dynamic effects across the entire visible module surface. This is the same addressable standard used by premium fans, GPU lighting, and motherboard headers on modern gaming platforms.

> **Critical compatibility note**: Never connect a 5V ARGB device to a 12V RGB header or vice versa. The voltage mismatch will damage the device. Always check your motherboard manual to confirm the header type (3-pin 5V ARGB vs 4-pin 12V RGB) before connecting.

## Performance: Why CL16 Matters in RGB Memory

It is common for RGB memory kits to prioritize visual impact over timing performance — delivering eye-catching lighting with loose CL22 or worse timings that underperform their advertised frequency. Concord takes a different position: the CL16 latency specification is the foundation of the product, not a footnote.

**Real latency comparison at DDR4-3200:**
- Concord CL16 @ 3200 MT/s: **5.0 nanoseconds** true latency
- Standard CL22 @ 3200 MT/s: **6.875 nanoseconds** true latency
- **Concord is 37.5% faster in memory command response** at the same clock speed

In gaming, this matters most in CPU-bound scenarios — competitive esports titles (CS2, Valorant, League of Legends), strategy games, and any title running above 144fps where memory latency directly affects frame timing consistency.
