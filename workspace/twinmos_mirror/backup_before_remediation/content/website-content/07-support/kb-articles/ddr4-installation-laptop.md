# How to Install DDR4 Laptop Memory (SODIMM)

This guide explains how to install or upgrade DDR4 SODIMM memory in a compatible laptop.

## Before You Begin

### Prerequisites
- Laptop with a DDR4 SODIMM slot
- TwinMOS DDR4 SODIMM module
- Small Phillips-head screwdriver
- Anti-static wrist strap (recommended)

### Safety Notes
- Power off and unplug the laptop.
- Ground yourself before handling memory.

## Step-by-Step Installation

### Step 1: Access the Memory Bay
Remove the bottom panel or memory compartment cover using the appropriate screws.

### Step 2: Locate the Slot
Identify the DDR4 SODIMM slot. Note that DDR4 and DDR5 SODIMMs have different notch positions and are not interchangeable.

### Step 3: Remove Existing Module (if applicable)
Push the retention clips outward. The module will pop up at an angle. Remove it by the edges.

### Step 4: Insert the New Module
Align the notch with the slot key. Insert at a 30-degree angle and press down until both clips engage.

### Step 5: Reassemble and Test
Replace the cover, reconnect power, and boot the laptop. Verify the new memory in BIOS or system settings.

## Troubleshooting

**Laptop won't boot:**
- Reseat the module.
- Confirm DDR4 compatibility (not DDR5).
- Test with the original module.
