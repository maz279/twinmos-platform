# Blog Post Template

Use this template for consistent TwinMOS blog post formatting.

```yaml
---

slug: "[url-friendly-slug]"

```

## Content Structure

### 1. Introduction (2-3 paragraphs)
- Hook the reader
- State the topic and its relevance
- Preview what they'll learn

### 2. Body Sections
- Use H2 for major sections
- Use H3 for subsections
- Include tables, lists, and visuals where appropriate
- Link to relevant TwinMOS products and explainers

### 3. Key Takeaways
- Bulleted summary of main points
- Actionable insights

### 4. Conclusion
- Reinforce main message
- Include product CTA where relevant
- Invite engagement (comments, social sharing)

## Style Guidelines

- **Tone**: Professional but approachable
- **Length**: 800-1,500 words for standard posts; 2,000+ for deep dives
- **Images**: Include hero image and inline visuals; use alt text
- **Links**: Internal links to TwinMOS products and explainers; external sources cited
- **CTAs**: One primary call-to-action per post

## SEO Checklist

- [ ] Target keyword in title, first paragraph, and at least one H2
- [ ] Meta description under 160 characters
- [ ] Descriptive slug
- [ ] Alt text on all images
- [ ] Internal links to related content
- [ ] External sources cited and linked
