## 1. Methodology

### 1.1 Research Process

1. **Seed keywords** — Broad head terms from product categories: "DDR5 RAM", "NVMe SSD", "USB flash drive", "portable SSD".
2. **Expand** — Use Google Keyword Planner, Ahrefs Keywords Explorer, and competitor research to identify related and long-tail terms.
3. **Filter by intent** — Classify each keyword by search intent (Informational / Commercial / Transactional / Navigational).
4. **Difficulty assessment** — Assess keyword difficulty (KD) and prioritise low-competition / high-intent keywords for early wins.
5. **Map to pages** — Assign each keyword to a specific page URL (one primary keyword per URL).
6. **Review** — Product Manager validates technical accuracy of keyword claims; Marketing Director approves final list.

### 1.2 Intent Classification

| Intent | Description | Example | Content Type |
|--------|-------------|---------|-------------|
| Informational | User wants to learn | "what is DDR5 RAM" | Learn Hub article |
| Commercial | User is researching for a purchase | "best DDR5 RAM 2026" | Buying guide, category page |
| Transactional | User is ready to buy / take action | "buy VOLTX DDR5 32GB" | Product detail page, Where to Buy |
| Navigational | User wants a specific site/page | "TwinMOS support" | Support hub |

### 1.3 Priority Tiers

| Tier | Criteria | Action |
|------|----------|--------|
| P0 | High volume, commercial/transactional intent, aligns with Phase 1 products | Target in launch content |
| P1 | Medium volume, informational, builds topical authority | Target in Learn Hub / buying guides |
| P2 | Long-tail, low competition, specific product or regional | Target in Phase 2 content expansion |
| P3 | Brand, review, or competitor comparison | Target in Phase 2–3 |
