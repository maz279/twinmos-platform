## 1. Purpose and Scope

This guide defines the operational procedures for managing the TwinMOS customer loyalty program ("TwinMOS Rewards"). It covers:

- Program structure and tier management
- Point earning and redemption rules
- Member enrollment and account management
- Promotional campaigns and bonuses
- Customer service for loyalty inquiries
- Reporting and program analytics
- Fraud prevention and account security

**Scope:** All loyalty program operations for registered customers of the TwinMOS e-commerce platform (Phase 3).

---

## 2. Program Overview

### 2.1 Program Name and Branding

- **Program Name:** TwinMOS Rewards
- **Currency:** TwinMOS Points (TMP)
- **Tagline:** "Build More. Earn More. Reward Yourself."

### 2.2 Membership Tiers

| Tier | Name | Qualification | Benefits |
|:---|:---|:---|:---|
| **Bronze** | Member | Enroll (free) | 1 TMP per $1 spent; Birthday bonus; Early access to sales |
| **Silver** | Enthusiast | 500 TMP earned in 12 months | 1.25 TMP per $1; Free standard shipping; Exclusive products |
| **Gold** | Pro Builder | 1,500 TMP earned in 12 months | 1.5 TMP per $1; Free express shipping; Priority support; Beta access |
| **Platinum** | Elite | 3,000 TMP earned in 12 months | 2 TMP per $1; Dedicated manager; Custom builds; Event invites |

**Tier Evaluation:** Annually on enrollment anniversary. Members retain achieved tier for 12 months minimum.

### 2.3 Point Value

| Conversion | Rate |
|:---|:---|
| Point earning (Bronze) | 1 TMP per $1 USD spent (or equivalent) |
| Point redemption | 100 TMP = $1 USD discount |
| Minimum redemption | 500 TMP ($5 discount) |
| Maximum redemption per order | 10,000 TMP ($100 discount) |
| Point expiration | 24 months from earning date |

## 3. Member Enrollment

### 3.1 Enrollment Channels

| Channel | Process | Auto-Enrolled? |
|:---|:---|:---|
| Website account creation | Checkbox during registration | No (opt-in) |
| Post-purchase email | Click link in order confirmation | No (opt-in) |
| Product registration | Checkbox during warranty registration | No (opt-in) |
| Promotional campaign | Sign-up via landing page | Yes (if explicitly submitted) |
| Partner referral | Referred by existing member | Yes (upon first purchase) |

### 3.2 Enrollment Requirements

- Valid email address
- Age 18+ (or legal age in jurisdiction)
- One account per person
- Agreement to program terms and conditions

### 3.3 Welcome Process

1. Enrollment confirmed via email
2. Welcome email sent with:
   - Program overview
   - Current tier and benefits
   - Point balance (0 TMP)
   - How to earn and redeem
   - Referral link (earn 100 TMP per successful referral)

## 5. Redeeming Points

### 5.1 Redemption Methods

| Method | Description | Minimum |
|:---|:---|:---|
| Order discount | Apply TMP at checkout for $ off | 500 TMP |
| Free shipping | Redeem for free standard shipping | 300 TMP |
| Exclusive products | Purchase members-only items with TMP | Varies |
| Gift cards | Convert TMP to gift card | 1,000 TMP |
| Charity donation | Donate TMP value to partner charity | 500 TMP |

### 5.2 Checkout Redemption Process

1. Customer logged into account
2. At checkout, "Apply Points" section visible
3. Customer enters points to redeem (or clicks "Apply All")
4. System validates: sufficient balance, minimum met, not exceeding max
5. Discount applied to order total
6. Points deducted immediately (pending order completion)
7. If order cancelled: points refunded within 24 hours

### 5.3 Redemption Restrictions

- Points cannot be redeemed for cash
- Points cannot be transferred between accounts
- Points cannot be used on gift card purchases
- Points cannot be combined with certain promotional codes (specified per promotion)
- Points used on returned items are refunded to account

| Feature | Access |
|:---|:---|

| Transaction history | Full earning and redemption log |
| Tier progress | Visual progress to next tier |
| Expiring points alert | 60 days before expiration |

### 6.2 Account Maintenance

| Task | Frequency | Owner |
|:---|:---|:---|
| Tier evaluation and updates | Daily (anniversary-based) | System |
| Expired point purge | Monthly | System |
| Inactive account review | Quarterly | Marketing |
| Fraud pattern detection | Daily | System + Finance |
| Member communication | As triggered | System |

### 6.3 Account Issues

| Issue | Resolution |
|:---|:---|
| Missing points | Verify activity, manually credit if valid |
| Wrong tier | Review qualification period, correct if error |
| Points not applying at checkout | Check restrictions, minimums, account login |
| Account merge (duplicate) | Transfer points to primary, close duplicate |
| Deceased member | Transfer to estate or close per request |

## 7. Customer Service

### 7.1 Common Loyalty Inquiries

| Inquiry | Response |
|:---|:---|
| "How do I earn points?" | Explain earning activities, share program guide link |
| "Why didn't I get points?" | Check order status (must ship), review eligibility, credit if error |
| "When do my points expire?" | Show expiration date per point batch; 24 months from earning |
| "How do I redeem?" | Guide through checkout process or account dashboard |
| "Can I transfer points?" | No, points are non-transferable |
| "I forgot to log in when ordering" | If order within 30 days, link to account and credit points |
| "My tier is wrong" | Review earning history, correct tier if system error |

### 7.2 Goodwill Adjustments

Agents may manually credit points for:
- System errors (documented)
- Service recovery (compensation for poor experience)
- Promotional promises not auto-credited

**Approval required:**
- < 200 TMP: Agent discretion
- 200–500 TMP: Supervisor approval
- > 500 TMP: Marketing Manager approval

## 8. Fraud Prevention

### 8.1 Monitoring Rules

| Rule | Trigger | Action |
|:---|:---|:---|
| Velocity | >5 reviews in 24 hours | Flag for review |
| Duplicate accounts | Same email, phone, or address | Merge or suspend |
| Self-referral | Referrer and referred share details | Cancel referral bonus |
| Refund abuse | >3 returns in 30 days | Review account, suspend points |
| Fake reviews | Pattern of low-quality reviews | Reject reviews, suspend points |
| Bot detection | Automated behavior patterns | CAPTCHA challenge, account review |

### 8.2 Account Suspension

Accounts may be suspended for:
- Confirmed fraud or abuse
- Multiple policy violations
- Chargebacks on loyalty-related purchases
- Attempted point manipulation

Suspended accounts:
- Lose ability to earn or redeem
- Retain existing points (frozen)
- May appeal via support ticket
- Reviewed by Loyalty Program Manager
