## 1. Purpose and Scope

This guide defines the end-to-end operational procedures for fulfilling customer orders placed through the TwinMOS e-commerce platform (Phase 3). It covers:

- Order receipt and validation
- Pick, pack, and ship workflows
- Carrier management and shipping
- Tracking and delivery confirmation
- Exception handling (damaged, lost, returned shipments)
- Returns and reverse logistics
- Performance metrics and continuous improvement

**Scope:** All direct-to-consumer and B2B orders fulfilled from TwinMOS warehouses or designated fulfillment centers.

## 3. Order Fulfillment Workflow

### Phase 1: Order Receipt (0–2 hours)

| Step | Action | System | Owner |
|:---|:---|:---|:---|
| 1.1 | Customer places order on website | Medusa.js | Customer |
| 1.2 | Payment authorized and confirmed | Stripe / PayPal | System |
| 1.3 | Order created in Medusa with "Paid" status | Medusa | System |
| 1.4 | Order routed to appropriate warehouse | Routing engine | System |
| 1.5 | Order confirmation email sent to customer | SendGrid | System |
| 1.6 | Order appears in warehouse management system (WMS) | Medusa → WMS API | System |

**Order Routing Logic:**
- Ship from warehouse closest to delivery address
- If stock unavailable at primary warehouse, check next closest
- If out of stock everywhere, flag for backorder handling
- B2B bulk orders may be routed to designated distribution center

### Phase 2: Picking (2–24 hours)

| Step | Action | System | Owner |
|:---|:---|:---|:---|
| 2.1 | Pick list generated by WMS | WMS | System |
| 2.2 | Warehouse staff receives pick assignment | Handheld scanner / tablet | Warehouse Staff |
| 2.3 | Items picked from warehouse locations | Barcode scan per item | Warehouse Staff |
| 2.4 | Pick accuracy verified | WMS scan validation | System |
| 2.5 | Items moved to packing station | Physical transfer | Warehouse Staff |

**Picking Methods:**
- **Single order pick:** One order at a time (standard for D2C)
- **Batch pick:** Multiple orders picked together, sorted at pack station (high volume)
- **Zone pick:** Staff pick from assigned zones, consolidated at pack station (large warehouse)

### Phase 3: Packing (Concurrent with picking)

| Step | Action | Standard |
|:---|:---|:---|
| 3.1 | Verify items against order | 100% scan check |
| 3.2 | Select appropriate packaging | Based on size, fragility, value |
| 3.3 | Apply protective materials | Anti-static bag for memory/SSD, bubble wrap |
| 3.4 | Include packing slip | Order details, return instructions |
| 3.5 | Include promotional materials | If applicable (inserts, stickers) |
| 3.6 | Seal package | Tamper-evident tape |
| 3.7 | Apply shipping label | Carrier label with tracking |
| 3.8 | Scan package barcode to confirm packed | WMS update |

**Packaging Standards:**

| Product Type | Packaging | Protection |
|:---|:---|:---|
| Memory modules | Anti-static blister pack + box | Anti-static bag, foam insert |
| SSDs | Retail box | Anti-static bag, foam insert |
| USB drives | Retail blister or box | Bubble wrap |
| Memory cards | Retail blister | Bubble wrap |
| Bulk orders | Master carton | Dividers, cushioning |

### Phase 4: Shipping (0–24 hours after packing)

| Step | Action | System |
|:---|:---|:---|
| 4.1 | Carrier manifest generated | WMS / Carrier API |
| 4.2 | Packages consolidated for carrier pickup | Physical |
| 4.3 | Carrier scans and collects packages | Carrier handheld |
| 4.4 | Tracking information received | Carrier API |
| 4.5 | Order status updated to "Shipped" | Medusa |
| 4.6 | Shipping confirmation email sent | SendGrid |
| 4.7 | Tracking number available in customer account | Medusa |

### Phase 5: Delivery and Confirmation

| Step | Action | System |
|:---|:---|:---|
| 5.1 | Carrier delivers package | Carrier |
| 5.2 | Delivery confirmation received | Carrier webhook |
| 5.3 | Order status updated to "Delivered" | Medusa |
| 5.4 | Delivery confirmation email sent | SendGrid |
| 5.5 | Customer satisfaction survey triggered | Chatwoot / Email (48 hours later) |

## 5. Exception Handling

### 5.1 Address Issues

| Issue | Resolution |
|:---|:---|
| Invalid address | Contact customer for correction; hold order |
| Address change request | Update before shipment; if shipped, intercept or redirect (carrier fees apply) |
| Undeliverable (returned) | Contact customer, reship or refund |

### 5.2 Stock Issues

| Issue | Resolution |
|:---|:---|
| Item out of stock after order | Notify customer, offer substitution or backorder |
| Partial stock available | Ship available items, backorder remainder with customer consent |
| Discontinued item | Notify customer, offer alternative or full refund |

### 5.3 Damaged or Lost Shipments

| Issue | Resolution | Timeline |
|:---|:---|:---|
| Damaged in transit | File carrier claim; ship replacement immediately | Replacement within 48 hours |
| Lost in transit | File carrier claim; ship replacement or refund after investigation | 7–14 days |
| Delivered but not received | Verify with carrier; investigate; reship or refund | 3–5 days |

### 5.4 Customer-Initiated Changes

| Request | Before Shipment | After Shipment |
|:---|:---|:---|
| Cancel order | Process cancellation and full refund | Follow return process |
| Change item | Edit order if unshipped | Follow return + new order |
| Change address | Update if unshipped | Carrier redirect (if possible) |
| Change shipping speed | Update if unshipped | Not possible |

## 6. Returns and Reverse Logistics

### 6.1 Return Authorization

1. Customer requests return via website or support
2. Eligibility verified (within return window, condition)
3. Return Merchandise Authorization (RMA) number issued
4. Return label emailed to customer (prepaid for defective; customer-paid for change-of-mind)
5. Customer ships item with RMA number visible

### 6.2 Receiving Returns

| Step | Action | Owner |
|:---|:---|:---|
| 6.2.1 | Package received at warehouse | Receiving staff |
| 6.2.2 | RMA number scanned, matched to order | Receiving staff |
| 6.2.3 | Item inspected for condition | QC staff |
| 6.2.4 | Condition documented (photos if needed) | QC staff |
| 6.2.5 | Disposition: Resellable / Refurbish / Dispose | QC lead |
| 6.2.6 | Inventory updated | WMS |
| 6.2.7 | Refund or exchange processed | Finance / System |

### 6.3 Return Dispositions

| Condition | Action | Restocking |
|:---|:---|:---|
| Unopened, resellable | Return to inventory | No fee |
| Opened, like-new | Return to inventory | 15% restocking fee |
| Opened, minor wear | Refurbish or discount sale | 25% restocking fee |
| Defective | RMA to supplier or dispose | No fee; full refund |
| Damaged by customer | Dispose or return to customer | No refund |

## 7. Performance Metrics

| Metric | Target | Measurement |
|:---|:---|:---|
| Order-to-ship time | < 24 hours (standard) | Time from "Paid" to "Shipped" |
| Same-day ship rate | > 50% of orders | Orders shipped same day as paid |
| Pick accuracy | > 99.5% | (1 - errors/total picks) × 100 |
| Pack accuracy | > 99.8% | (1 - errors/total packs) × 100 |
| On-time delivery | > 95% | Delivered within promised window |
| Damage rate | < 0.5% | Damaged deliveries / total deliveries |
| Return rate | < 5% | Returns / total orders |
| Cost per order | Benchmarked monthly | Total fulfillment cost / orders |
