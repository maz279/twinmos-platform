# TwinMOS Website — Imagery & Photography Guide

**Document ID:** E.1.10
**Version:** 1.0
**Status:** Final
**Date:** 2026-05-01

## 1. Purpose

Defines photography and imagery standards for the TwinMOS website.

## 2. Product Photography

### 2.1 Hero Images

- Resolution: 2400x1600px minimum
- Aspect: 3:2
- Background: Clean white or contextual
- Lighting: Even, no harsh shadows

### 2.2 Product Thumbnails

- Resolution: 800x800px
- Aspect: 1:1
- Background: Pure white `#FFFFFF`
- Format: WebP with JPEG fallback

## 3. Lifestyle Photography

### 3.1 Gaming

- Dynamic action shots
- RGB lighting visible
- Enthusiast-focused compositions

### 3.2 Professional

- Clean office environments
- Multi-monitor setups
- Corporate color grading

## 4. Image Treatment

### 4.1 Corporate

- Warm, neutral tones
- Slight contrast boost
- Clean and minimal

### 4.2 Gaming (VOLTX)

- Cool, high contrast
- Cyan accent boost
- Dramatic lighting

## 5. Technical Specs

| Property | Value |
|----------|-------|
| Color space | sRGB |
| DPI | 72 (web) |
| Format | WebP primary, JPEG fallback |
| Max file size | 200KB (hero), 80KB (thumbnail) |

## 6. Alt Text Guidelines

- Product: "TwinMOS [Product Name] [Capacity] [Type]"
- Lifestyle: Descriptive scene context
- Decorative: Empty alt attribute
