**Document ID:** E.4.7
**Version:** 1.0
**Status:** Final
**Date:** 2026-05-01

## 1. Purpose

Defines onboarding and first-time user experience patterns.

## 2. Cookie Consent

- Fixed bottom banner
- "Accept All" and "Customize" buttons
- Focus trap while open

## 3. Newsletter Prompt

- Inline footer form
- Optional exit-intent modal (desktop)

## 4. Feature Tours

- Tooltip-style highlights
- Step indicators
- Skip option always available

## 5. Frequency Rules

| Element | First Show | Repeat |
|---------|-----------|--------|
| Cookie banner | Immediate | Never |
| Newsletter | 30s or exit | 30 days |
| Feature tour | First visit | Never |
