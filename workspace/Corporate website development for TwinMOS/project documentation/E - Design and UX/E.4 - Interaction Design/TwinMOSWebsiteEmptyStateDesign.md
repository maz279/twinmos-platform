# TwinMOS Website — Empty State Design

**Document ID:** E.4.5
**Version:** 1.0
**Status:** Final
**Date:** 2026-05-01

## 1. Purpose

Defines design patterns for empty states across the website.

## 2. Structure

- Illustration/Icon (96px)
- Headline (H3)
- Description
- Primary CTA
- Optional secondary link

## 3. Examples

### 3.1 Search No Results

- Headline: "No results found"
- CTA: "Browse All Products"

### 3.2 Compare List Empty

- Headline: "No products to compare"
- CTA: "Browse Products"

### 3.3 Support Tickets (None)

- Headline: "No support tickets yet"
- CTA: "Submit a Ticket"

## 4. Visual Design

- Icon color: `#9CA3AF`
- Centered alignment
- 64px vertical padding
