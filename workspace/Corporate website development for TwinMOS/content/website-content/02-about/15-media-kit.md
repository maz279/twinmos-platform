## Brand Logos

### Logo Package Contents
| Variant | Formats | Use Case |
|---------|---------|----------|
| **Full-Color Logo** | PNG, SVG, EPS | Primary use on light backgrounds |
| **Dark Background Variant** | PNG, SVG | Use on dark or colored backgrounds |
| **Monochrome / Grayscale** | PNG, SVG | Single-color applications, fax, watermark |
| **Reversed / White** | PNG, SVG | Use on dark backgrounds or images |

### Logo Usage Guidelines

**Clear Space**
- Minimum clear space: Equal to the height of the "T" in TwinMOS
- No text, graphics, or other elements within the clear space zone

**Minimum Size**
- Print: 30mm width minimum
- Digital: 120px width minimum
- Never use below minimum size — legibility is compromised

**Prohibited Uses**
- Do not distort, rotate, or alter logo proportions
- Do not apply effects (shadows, gradients, outlines) not provided in official files
- Do not change logo colors outside approved variants
- Do not place logo on busy backgrounds without sufficient contrast
- Do not use outdated logo versions

## Brand Guidelines

### Comprehensive Brand Guidelines (PDF)

The TwinMOS Brand Guidelines document covers:

**1. Brand Identity**
- Logo system and usage rules
- Clear space and minimum sizes
- Incorrect usage examples

**2. Color Palette**
| Color | Hex | RGB | CMYK | Usage |
|-------|-----|-----|------|-------|
| Primary Blue | #0056D2 | 0, 86, 210 | 100, 60, 0, 0 | Primary brand color |
| Accent Orange | #FF6B35 | 255, 107, 53 | 0, 65, 80, 0 | CTAs, highlights |
| Dark Navy | #1A1A2E | 26, 26, 46 | 90, 80, 50, 60 | Text, backgrounds |
| Light Gray | #F8F9FA | 248, 249, 250 | 2, 1, 1, 0 | Backgrounds |

**3. Typography**
- Primary font: Inter (Google Fonts) or equivalent sans-serif
- Heading weights: Bold (700)
- Body weight: Regular (400)
- Digital minimum size: 14px body, 24px H3, 32px H2, 48px H1

**4. Tone of Voice**
- Professional yet approachable
- Technical when necessary, never jargon-heavy
- Action-oriented and confident
- Global perspective with local sensitivity

**5. Photography Style**
- Product: Clean, high-contrast, neutral backgrounds
- Lifestyle: Natural light, diverse subjects, authentic settings
- Corporate: Professional, approachable, diverse representation

**6. Social Media Templates**
- Instagram post template (1080×1080)
- Twitter/X post template (1200×675)
- LinkedIn post template (1200×627)
- Facebook post template (1200×630)
