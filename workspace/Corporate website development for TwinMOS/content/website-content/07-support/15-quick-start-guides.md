# Quick-Start Guides

Get up and running with your TwinMOS product using these concise, illustrated guides. Each guide covers the essential steps for installation and initial setup.

## Memory Modules

- [DDR5 Desktop Installation](/support/kb/ddr5-installation-desktop/) — Install VOLTX DDR5 in a desktop PC.
- [DDR5 Laptop Installation](/support/kb/ddr5-installation-laptop/) — Upgrade notebook memory with DDR5 SODIMM.
- [DDR4 Desktop Installation](/support/kb/ddr4-installation-desktop/) — Install DDR4 desktop memory.
- [DDR4 Laptop Installation](/support/kb/ddr4-installation-laptop/) — Upgrade notebook memory with DDR4 SODIMM.

## SSDs

- [How to Install an M.2 NVMe SSD](/support/kb/how-to-install-m2-nvme-ssd/) — Install CoreX Pro Gen5, Xtreme Gen4, or Alpha Pro Gen3.
- [How to Install a 2.5-inch SATA SSD](/support/kb/how-to-install-2.5-sata-ssd/) — Install Hyper H2 Ultra SATA SSD.
- [How to Clone Windows to a New SSD](/support/kb/how-to-clone-windows-to-new-ssd/) — Migrate your OS without reinstalling.
- [How to Initialize an SSD in Windows](/support/kb/how-to-initialize-an-ssd-windows/) — Format and prepare a new drive.

## Portable Storage

- [How to Format a Portable SSD](/support/kb/how-to-format-portable-ssd/) — Prepare ELITE Drive Pro for use on Windows, macOS, or Linux.

## BIOS Configuration

- [How to Enable XMP in BIOS](/support/kb/how-to-enable-xmp-bios/) — Unlock rated DDR5 speeds on Intel platforms.
- [How to Enable AMD EXPO in BIOS](/support/kb/how-to-enable-amd-expo-bios/) — Unlock rated DDR5 speeds on AMD platforms.

## Video Guides

For visual learners, our [Installation Guides Hub](/support/install-guides/) features video walkthroughs alongside text instructions.

Each quick-start guide is available in multiple formats:

| Format | Description | Best For |
|---|---|---|
| PDF | Printable one-page guide | Workshop reference, first-time setup |
| Video | 2–5 minute walkthrough | Visual learners, complex installations |
| Interactive | Step-by-step with images | Self-paced learning |

## Print-Friendly Checklist

Before you begin any installation, ensure you have:
- [ ] Compatible system/motherboard
- [ ] Required tools (screwdriver, anti-static strap)
- [ ] Adequate workspace with good lighting
- [ ] Backup of important data (for SSD upgrades)
- [ ] Access to BIOS/UEFI (for memory configuration)
