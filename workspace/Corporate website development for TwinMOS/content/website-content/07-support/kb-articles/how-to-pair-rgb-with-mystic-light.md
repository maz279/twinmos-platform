# How to Pair RGB with MSI Mystic Light

MSI Mystic Light allows you to control and synchronize RGB lighting across compatible components, including TwinMOS VOLTX DDR5 memory modules.

## Before You Begin

### Prerequisites
- MSI motherboard with Mystic Light support
- TwinMOS VOLTX DDR5 RGB module(s) installed
- MSI Center with Mystic Light module installed

## Step-by-Step Instructions

### Step 1: Install MSI Center
Download MSI Center from the MSI support page. During setup, select the **Mystic Light** module.

### Step 2: Open Mystic Light
Launch MSI Center and open the Mystic Light application. Your TwinMOS VOLTX DDR5 modules should appear under the "DRAM" section.

### Step 3: Select an Effect
Choose from available lighting effects:
- **Static**
- **Breathing**
- **Flashing**
- **Double Flashing**
- **Lightning**
- **Rainbow**
- **Stack**
- **CPU Temperature**

### Step 4: Customize and Apply
Select colors and speeds as desired. Click **Apply** to save the settings.

### Step 5: Sync All Devices
Use the chain link icon to synchronize all Mystic Light-compatible devices to the same effect.

## Troubleshooting

**DRAM not showing:**
- Ensure the memory is fully seated.
- Update MSI Center and motherboard BIOS.
- Reinstall the Mystic Light module.
