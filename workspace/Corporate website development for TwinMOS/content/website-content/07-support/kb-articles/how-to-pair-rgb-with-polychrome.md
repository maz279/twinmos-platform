# How to Pair RGB with ASRock Polychrome Sync

ASRock Polychrome Sync allows you to control RGB lighting on ASRock motherboards and compatible peripherals, including TwinMOS VOLTX DDR5 memory modules.

## Before You Begin

### Prerequisites
- ASRock motherboard with Polychrome Sync support
- TwinMOS VOLTX DDR5 RGB module(s) installed
- ASRock Polychrome Sync software installed

## Step-by-Step Instructions

### Step 1: Install Polychrome Sync
Download the latest Polychrome Sync utility from the ASRock support page for your motherboard model.

### Step 2: Open Polychrome Sync
Launch the application. Your TwinMOS VOLTX DDR5 modules should appear under the "DRAM" category in the device list.

### Step 3: Select a Lighting Effect
Choose from the available effects:
- **Static**
- **Breathing**
- **Strobe**
- **Cycling**
- **Random**
- **Music**
- **Wave**

### Step 4: Customize
Select colors from the palette and adjust speed and direction where applicable.

### Step 5: Apply
Click **Apply** to save the settings to the module.

## Troubleshooting

**DRAM not showing in Polychrome Sync:**
- Reseat the memory modules.
- Update Polychrome Sync and motherboard BIOS.
- Some ASRock boards require BIOS updates for DDR5 RGB support.
