# How to Pair RGB with Gigabyte RGB Fusion

Gigabyte RGB Fusion lets you control RGB lighting on Gigabyte motherboards and compatible components, including TwinMOS VOLTX DDR5 memory.

## Before You Begin

### Prerequisites
- Gigabyte motherboard with RGB Fusion support
- TwinMOS VOLTX DDR5 RGB module(s) installed
- RGB Fusion 2.0 software installed

## Step-by-Step Instructions

### Step 1: Install RGB Fusion 2.0
Download RGB Fusion 2.0 from the Gigabyte support page or install it via the App Center.

### Step 2: Launch the Software
Open RGB Fusion 2.0. Your TwinMOS VOLTX DDR5 modules should appear in the device list under "DRAM."

### Step 3: Choose an Effect
Select from available lighting modes:
- **Static**
- **Pulse**
- **Flash**
- **Double Flash**
- **Color Cycle**
- **Random**
- **Music**
- **Game Mode**

### Step 4: Customize Colors
Click on the color wheel or presets to customize the lighting. Adjust speed and brightness as desired.

### Step 5: Apply and Save
Click **Apply** to activate the settings. Save to a profile if you want to switch between configurations.

## Troubleshooting

**DRAM not detected:**
- Reseat the memory modules.
- Update RGB Fusion 2.0 and motherboard BIOS.
- Ensure no conflicting RGB software is running.
