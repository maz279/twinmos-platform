## Product Overview

The TwinMOS VOLTX RGB DDR5 U-DIMM series fuses cutting-edge DDR5 performance with customizable RGB lighting. Built for gamers, modders, and PC enthusiasts, these modules deliver the speeds modern platforms demand while adding a vibrant visual dimension to any build.

VOLTX RGB DDR5 modules feature a diffused RGB light bar integrated into a high-quality Dark Maroon aluminum heatsink. The lighting is addressable and synchronizes seamlessly with major motherboard RGB ecosystems, allowing users to coordinate memory lighting with case fans, CPU coolers, and LED strips for a unified aesthetic.

Available as **16GB and 32GB single modules** or in **matched dual-channel kits (32GB = 2×16GB; 64GB = 2×32GB)**, VOLTX RGB is the ideal choice for builders who refuse to compromise on either performance or style.

## Key Features

### Gaming-Optimized Performance
At 5600MHz and 6000MHz, VOLTX RGB DDR5 reduces latency and increases throughput in CPU-bound games. Higher memory frequencies directly translate to improved frame rates and smoother gameplay in titles like Cyberpunk 2077, Call of Duty, Microsoft Flight Simulator, and strategy games.

### Synchronized RGB Lighting
The addressable RGB light bar integrates with motherboard software to create unified lighting themes across all compatible components. Unlike basic RGB (single color for all LEDs), addressable RGB allows each LED to display a different color, enabling complex patterns like rainbow waves and music-reactive effects.

### Dual-Channel Kits
Each kit is matched at the factory to ensure tight timing consistency between modules. This guarantees stable dual-channel operation, which is essential for maximizing memory bandwidth on modern platforms. Factory matching eliminates compatibility issues that can arise when mixing modules from different batches.

### Premium Heatsink Design
The Dark Maroon aluminum heatsink not only supports the RGB diffuser but also maintains thermal stability during extended gaming sessions. The thermally conductive interface between the ICs and heatsink, combined with the fortified PMIC cooling design, keeps temperatures in check even during marathon gaming sessions.

### Plug-and-Play Overclocking
Intel XMP 3.0 and AMD EXPO profiles are pre-programmed into each module. Enabling the profile in BIOS instantly configures the memory to its rated speed and timings without manual adjustment. XMP 3.0 supports up to five profiles per module for maximum flexibility.

### On-Die ECC
DDR5 on-die ECC corrects bit errors within the memory chip itself, improving data integrity for all users. While not a replacement for full system ECC, it adds a valuable layer of protection for gaming and creative workloads.

## Installation Guide

### Memory Installation
1. Power off the PC and disconnect the power cable
2. Open the chassis and locate the DDR5 slots
3. Align the notch on the VOLTX RGB module with the slot key
4. Press down firmly until both retention clips click
5. Ensure the module sits level and clips are fully closed

### RGB Setup
1. Install motherboard RGB control software (Armoury Crate, GCC, MSI Center, or Polychrome SYNC)
2. Boot into Windows and launch the RGB software
3. The VOLTX RGB modules should be automatically detected
4. Select your preferred lighting effect and color
5. Apply settings — lighting will persist across reboots

**Note**: RGB control does not require XMP/EXPO to be enabled. Lighting functions at JEDEC default speeds.
