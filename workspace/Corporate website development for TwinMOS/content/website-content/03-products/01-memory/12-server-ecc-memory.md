## ECC Memory Types

### ECC Registered (RDIMM)

Registered memory modules include a register chip that buffers address and command signals between the memory controller and the DRAM chips. This reduces electrical load on the memory controller and enables systems to support larger memory configurations — often hundreds of gigabytes per server.

**Best For**:
- Enterprise servers and virtualization hosts
- Database servers (MySQL, PostgreSQL, SQL Server)
- High-performance computing (HPC) clusters
- Cloud infrastructure and colocation facilities

**Advantages**:
- Supports highest memory capacities per channel
- Reduced electrical load on memory controller
- Standard for enterprise server platforms

**Trade-offs**:
- Slightly higher latency than UDIMM
- Higher cost per module
- Requires RDIMM-compatible platforms

### ECC Unbuffered (UDIMM)

ECC UDIMMs provide error correction without the additional register chip, offering lower latency than RDIMMs at the cost of reduced maximum capacity per channel.

**Best For**:
- Entry-level servers and small business servers
- Professional workstations (CAD, simulation, video editing)
- NAS appliances and storage servers
- Development and test environments

**Advantages**:
- Lower latency than RDIMM
- Lower cost per module
- Compatible with more workstation platforms

**Trade-offs**:
- Lower maximum capacity per channel
- Higher electrical load on memory controller
- Not suitable for highest-density configurations
