# 404 — Page Not Found

## Overview
The 404 error page is displayed when a user attempts to access a URL that does not exist on the TwinMOS website. It transforms a frustrating experience into a helpful navigation opportunity by providing multiple pathways to relevant content.

**HTTP Status**: 404 Not Found  
**Indexability**: Noindex (prevents search engines from indexing error pages)  
**Canonical**: Self-referencing

---

## Page Design

### Layout
- **Container**: Centered, max-width 800px
- **Background**: Light gray (#F8F9FA) or subtle brand pattern
- **Padding**: 80px vertical on desktop, 48px on mobile
- **Header**: Minimal header with logo only (no navigation to reduce clutter)
- **Footer**: Simplified footer with essential links only

### Visual Elements
- **Illustration**: Custom brand illustration (memory module with question mark, or abstract "lost connection" visual)
- **Size**: 240px wide on desktop, 160px on mobile
- **Style**: Flat vector, brand colors
- **Animation**: Subtle floating/bobbing animation (CSS, no JS required)

## SEO & Analytics

### Meta Tags
- `<meta name="robots" content="noindex, nofollow">`
- `<title>Page Not Found — TwinMOS Technologies</title>`
- No Open Graph tags (prevents social sharing of error pages)

### Analytics Tracking
Track 404 events to identify broken links and content gaps:
- **Event**: `404_error`
- **Parameters**:
  - `page_url`: The URL that returned 404
  - `referrer`: Where the user came from
  - `user_agent`: Browser/device info

### Redirect Monitoring
Log all 404s to identify:
- Broken internal links (fix in CMS)
- Missing product pages (check SKU mapping)
- Old URLs from previous website (implement 301 redirects)
