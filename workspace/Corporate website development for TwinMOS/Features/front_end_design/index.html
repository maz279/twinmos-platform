Responsive & PWA Layer — every screen, installable

The same editable sources adapt from a 390 px phone (burger nav, single-column stacking, scrollable spec tables) through 834 px tablets (two-up grids) to 1440 px desktops and 1600 px+ large monitors (wider wrap, 5-column bento).
